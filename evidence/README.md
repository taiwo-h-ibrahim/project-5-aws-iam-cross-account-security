# Project 5 — Evidence

This folder is intended to hold carefully selected screenshots supporting the AWS IAM cross-account access implementation and its validation.

## Evidence handling

Before adding screenshots to this public repository:

- Redact AWS account IDs, email addresses, personal identifiers, access portal URLs containing tenant-specific identifiers, and any other information that is not necessary to demonstrate the control.
- Never include passwords, access keys, secret keys, session tokens, recovery codes, or other credentials.
- Prefer cropped screenshots that show the relevant configuration or test result without exposing unrelated account details.
- Use descriptive filenames and reference each image in the evidence register.
- Do not present a screenshot of a simulator result as proof of a live API operation.

Only add screenshots that have been checked for sensitive information. The evidence register describes the evidence collected during the lab; it does not imply that every screenshot has already been uploaded to this repository.
